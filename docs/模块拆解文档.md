# 项目模块拆解

**项目名称**：FlowGenAll - 知识点聚合分析系统
**技术栈**：Vue 3 + NestJS + PostgreSQL + Redis + 阿里云通义千问

> **v2.0 改造说明（2026-02-25）**：系统从"多模态智能搜索引擎"改造为"知识点聚合分析系统"。
> M2（文件管理）、M5（搜索服务）、M6（搜索记录）、M8（导出服务）、WorkflowsModule 已废弃删除。
> 新增 M9（知识点模块）。

---

## 当前有效模块

### M1 - 用户认证模块
用户注册/登录/登出，JWT 认证和 Token 刷新。
- **实现位置**：`src/modules/auth/`

### M3 - 外部数据聚合模块
可选联网搜索，为 AI 分析提供外部资料增强。
- **实现位置**：`src/modules/search-aggregator/`

### M4 - AI 处理模块
调用阿里云通义千问进行知识点分类、关联分析和逻辑梳理。
- **实现位置**：`src/modules/ai-processing/`

### M9 - 知识点模块（新）
知识点 CRUD、按天查询、触发 AI 分析、分析记录管理。
- **实现位置**：`src/modules/knowledge/`
- **子功能**：
  - 知识点条目管理（增删查）
  - 按天聚合分析（SSE 流式输出）
  - 分析记录存储与查询

---

## 废弃模块（v2.0 删除）

| 模块 | 废弃原因 |
|------|---------|
| M2 - FilesModule | 不再需要文件上传 |
| M5 - SearchModule | 被 KnowledgeModule 替代 |
| M6 - SearchHistoryModule | 分析记录内置到 KnowledgeModule |
| M8 - ExportModule | 暂不需要 |
| WorkflowsModule | 与新功能无关 |

---

## 技术基础设施（非独立模块）

- **缓存层**：Redis 缓存 AI 分析结果和联网搜索结果，1 小时过期
- **限流层**：分析接口 10 次/分钟/用户（防止滥用）
