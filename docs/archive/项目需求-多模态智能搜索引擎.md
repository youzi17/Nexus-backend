项目需求文档（修订版）：多模态智能搜索引擎  
技术栈：Vue 3 + NestJS | AI 引擎：阿里云通义千问（Qwen）系列

1. 项目概述

本项目构建一个支持多模态输入（文本、图片、PDF、Word、Markdown）的智能搜索引擎。系统聚合多方平台资料，利用阿里云通义千问（Qwen）系列大模型进行深度理解、交叉验证与结构化整理，最终输出为高质量文本或可视化图像。前端采用 Vue 3（Composition API + TypeScript），后端采用 NestJS（TypeScript + REST/GraphQL），整体架构高内聚、低耦合，便于部署与扩展。

核心优势：全面采用国产、低成本、高性能的阿里云通义千问模型，显著降低 AI 调用成本，同时满足中文场景下的高精度理解与生成需求。

2. 核心功能需求

2.1 多模态输入处理
- 支持格式：
  - 文本（纯文本、URL）
  - 图片（JPG, PNG, WebP）
  - PDF（含扫描件与可编辑文本）
  - Word（.docx）
  - Markdown（.md）
- 预处理能力：
  - 图片 → 调用 阿里云通用文字识别（OCR）API 提取文字；如需图像语义理解，则调用 Qwen-VL。
  - PDF/Word → 使用 pdf-parse / mammoth.js 提取文本与表格；扫描 PDF 先经 OCR 处理。
  - Markdown → 解析为 AST 树，保留标题、列表、代码块等结构。
  - 所有内容统一注入上下文，供 Qwen 模型使用。

2.2 多源信息聚合
- 数据源策略：
  - 网页搜索：通过 SerpAPI（第三方聚合服务）获取百度、搜狗、Bing 的搜索结果摘要（替代昂贵的官方 Search API）。
  - 学术资源：直接调用 arXiv API、PubMed E-Utilities（免费）。
  - 知识库：集成 Wikipedia API、GitHub API（免费且开放）。
  - 内部知识库（可选）：支持对接企业 Confluence、Notion（通过 OAuth）。
- 动态插件机制：未来可扩展新增数据源适配器。

2.3 AI 整理与推理（基于通义千问）
- 核心模型：
  - Qwen-Max：用于复杂任务（多文档推理、长文本摘要、结构化输出），性能对标 GPT-4。
  - Qwen-Plus：平衡成本与性能，适用于大多数问答与整合场景。
  - Qwen-VL：处理图像理解任务（如“图中展示了什么趋势？”、“提取图表数据”）。
- AI 能力：
  - 多源信息交叉验证与去重
  - 生成带引用来源的结构化回答（支持 Markdown）
  - 用户指定输出风格（简洁/详细/报告体/思维导图大纲）
  - 支持 32K+ 上下文，可处理长文档输入

2.4 输出形式
- 文本输出：
  - 富文本（HTML）或 Markdown（带 来源1 引用）
  - 可下载为 .md 或 .txt
- 图像输出（可选）：
  - 自动生成 Mermaid 代码（前端渲染为流程图/时序图）
  - 调用 通义万相（Tongyi Wanxiang）API 生成信息图（Infographic）或概念图（按需启用，控制成本）

2.5 用户交互
- 搜索历史记录（本地 + 后端同步）
- 结果收藏、导出（PDF/Markdown/图片）
- 一键反馈（“有用”/“无用”），用于优化提示词与模型选择

3. 技术架构

3.1 前端（Vue 3）
- 框架：Vue 3 + Vite + TypeScript + Pinia + Vue Router
- UI 库：Naive UI（轻量、主题友好）
- 关键组件：
  - MultiFileUploader：支持拖拽上传、格式校验、预览（图片/PDF）
  - StreamingResponseViewer：支持 SSE 流式响应，实时显示 AI 生成过程
  - OutputSwitcher：切换“文本”/“图表”视图，支持 Mermaid 渲染

3.2 后端（NestJS）
- 核心模块：
  - UploadModule：文件接收、病毒扫描（ClamAV）、格式分发
  - OcrService：封装 阿里云 OCR API 调用
  - SearchAggregatorModule：调用 SerpAPI + arXiv + Wikipedia 等
  - QwenAIService：核心 AI 模块，封装 Qwen-Max/Plus/VL 调用、提示词模板、缓存（Redis）
  - OutputGeneratorModule：生成文本或调用通义万相（可选）
  - UserHistoryModule：记录用户会话与结果
- 基础设施：
  - 数据库：PostgreSQL（用户、任务、历史）
  - 缓存：Redis（缓存 Qwen 响应、搜索结果）
  - 文件存储：MinIO（私有化部署）或 阿里云 OSS
  - 异步队列：BullMQ（处理 PDF 解析、OCR 等耗时任务）

3.3 阿里云服务集成清单
功能   阿里云产品   说明
大语言模型   通义千问（DashScope）   使用 qwen-max / qwen-plus / qwen-vl-plus

OCR 文字识别   通用文字识别（OCR）   高精度中英文识别，新用户享免费额度

图像生成（可选）   通义万相（Tongyi Wanxiang）   按需调用，用于生成信息图

对象存储   阿里云 OSS   存储用户上传文件（24 小时后自动清理）

API 网关 & 监控   阿里云 API 网关 + ARMS   （可选）用于生产环境流量管理

成本优势：阿里云 DashScope 新用户赠送 ¥180 代金券，OCR 每月 1000 次免费，足以支撑 MVP 开发与初期运营。

4. API 接口设计（关键接口）

POST /api/v1/ai/search
{
  "query": "补充问题（可选）",
  "fileIds": ["f1", "f2"],
  "outputType": "text|mindmap|infographic",
  "model": "qwen-max|qwen-plus" // 默认 qwen-plus
}

响应（SSE 流式）：
event: chunk
data: {"content": "根据您提供的资料，..."}
...
event: sources
data: [{"title": "xxx", "url": "https://..."}]
...
event: done
data: {"image_url": "oss://.../result.png"} // 若为图像输出

其他接口
- POST /api/upload → 返回 fileId
- GET /api/history → 分页获取历史记录
- POST /api/feedback → 提交反馈

5. 非功能性需求

- 成本控制：优先使用 qwen-plus，复杂任务才升级到 qwen-max；OCR 调用前做格式判断。
- 安全性：
  - 所有外部 API 调用使用阿里云 RAM 角色临时凭证
  - 用户文件 24 小时自动过期
  - 输入内容过滤敏感词（可集成阿里云内容安全）
- 合规性：遵循《生成式 AI 服务管理暂行办法》，输出内容标注“AI 生成”。
- 部署：提供 docker-compose.yml，支持一键部署至阿里云 ECS。
