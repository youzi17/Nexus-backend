# 用户认证模块 (M1 - AuthModule)

> 用户注册、登录、登出，JWT 认证和 Token 刷新

## 模块定位

- **职责边界**: 用户身份认证（注册/登录/登出）、JWT Token 生成与验证、Token 刷新、当前用户信息获取
- **不负责**: 用户数据持久化（由 UsersModule 负责）、业务权限控制
- **依赖模块**:
  - `UsersModule` — 用户创建和查询
  - `@nestjs/jwt` — JWT Token 签发和验证
- **被依赖**: 所有需要认证的模块通过 `JwtAuthGuard` 和 `CurrentUser` 装饰器使用

## 数据模型

| 实体 | 文件路径 | 说明 |
|------|---------|------|
| `User` | `modules/users/user.entity.ts` | 用户实体，字段：id(UUID)、username、email、passwordHash、avatarUrl、preferences(JSONB)、role(enum) |

- 密码存储字段为 `passwordHash`（数据库列名 `password_hash`），使用 bcrypt 加密
- 角色枚举 `UserRole`: `user` / `advanced` / `admin`

## 接口概览

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| POST | `/auth/register` | 用户注册，返回用户信息 + tokens | 公开 |
| POST | `/auth/login` | 用户登录，返回用户信息 + tokens | 公开 |
| POST | `/auth/refresh` | 刷新 Token（滚动刷新，同时返回新的 access + refresh） | 公开 |
| POST | `/auth/logout` | 用户登出（客户端清除 Token，无服务端黑名单） | 需要 |
| GET | `/auth/profile` | 获取当前用户信息 | 需要 |

接口详细参数和响应格式见 `docs/接口文档.md` 第 1 节

## 核心业务逻辑

### 认证流程

```
注册/登录
    ↓
密码 bcrypt 加密/验证（salt rounds 从 BCRYPT_SALT_ROUNDS 环境变量读取，默认 10）
    ↓
生成 JWT Token:
  - access_token: JWT_EXPIRES_IN（默认 15m）
  - refresh_token: JWT_REFRESH_EXPIRES_IN（默认 7d）
  - JWT Payload: { sub: userId, email, role }
    ↓
返回 ApiResponseDto 统一格式
```

### 业务规则

- 注册时同时返回 tokens，用户无需再次登录
- 密码校验：最小 8 位，需包含大小写字母、数字、特殊字符（`register.dto.ts` 中 `@Matches` 正则）
- 登出为纯客户端行为，服务端仅返回成功响应
- Token 刷新为滚动刷新，同时生成新的 access_token 和 refresh_token

### 守卫和装饰器

| 名称 | 文件路径 | 说明 |
|------|---------|------|
| `JwtAuthGuard` | `guards/jwt-auth.guard.ts` | JWT 认证守卫，验证 Bearer Token |
| `RolesGuard` | `guards/roles.guard.ts` | 角色权限守卫 |
| `@CurrentUser()` | `decorators/current-user.decorator.ts` | 注入当前认证用户到 Controller 参数 |
| `@Public()` | `decorators/public.decorator.ts` | 标记公开路由，跳过 JWT 验证 |

## 模块协作

- **与 UsersModule**: 通过 `UsersService.create()` 创建用户、`findByEmail()` / `findById()` 查询用户
- **与其他模块**: 导出 `JwtAuthGuard`、`CurrentUser`、`Public` 装饰器供全局使用
- **响应格式**: 所有接口使用 `ApiResponseDto.success()` 统一返回

```

```

## 注意事项

- **环境变量**: `JWT_SECRET`、`JWT_REFRESH_SECRET`、`JWT_EXPIRES_IN`(默认 15m)、`JWT_REFRESH_EXPIRES_IN`(默认 7d)、`BCRYPT_SALT_ROUNDS`(默认 10)
- **sanitizeUser**: `auth.service.ts` 中 `sanitizeUser()` 方法会剥离 `passwordHash` 字段后返回用户信息
- **前端兼容**: 响应中用户字段使用下划线命名（`avatar_url`、`created_at`），与前端类型定义对齐
