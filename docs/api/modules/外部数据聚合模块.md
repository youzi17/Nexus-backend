# 外部数据聚合模块 (M3 - SearchAggregatorModule)

> 可选联网搜索，为 AI 分析提供外部资料增强

## 模块定位

- **职责边界**: 协调多个外部搜索适配器并行搜索、聚合结果、缓存管理、数据源状态管理
- **不负责**: AI 分析（由 AiProcessingModule 负责）、业务编排（由 KnowledgeModule 负责）
- **依赖模块**:
  - `ConfigModule` — 读取 Redis 和适配器配置
  - `TypeOrmModule` — 搜索源配置持久化
- **被依赖**: `KnowledgeModule` — 知识点分析时可选调用 `SearchAggregatorService.aggregateSearch()`

## 数据模型

| 实体 | 文件路径 | 说明 |
|------|---------|------|
| `SearchSource` | `entities/search-source.entity.ts` | 搜索源配置：name、description、enabled、priority、rateLimit、config(JSONB) |

详细字段设计见 `docs/数据库设计.md` 第 1.4 节

## 接口概览

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| POST | `/search/aggregate` | 聚合搜索（并行调用所有启用的数据源） | 需要 |
| GET | `/search/sources` | 获取数据源列表 | 需要 |
| GET | `/search/health` | 检查所有适配器可用性 | 需要 |
| POST | `/search/sources/:name/toggle` | 切换数据源启用/禁用状态 | 需要 |

接口详细参数和响应格式见 `docs/接口文档.md` 第 3 节

## 核心业务逻辑

### 聚合搜索流程

```
POST /search/aggregate { query, sources?, limit? }
    ↓
getEnabledSources() 查询启用的数据源（支持按 ID 或 name 筛选）
    ↓
Promise.allSettled() 并行调用所有适配器
    ↓
每个适配器：检查 Redis 缓存 → 缓存命中直接返回 / 未命中则执行搜索 → 写入缓存
    ↓
聚合结果：按数据源分组，失败的数据源记录 error 信息
    ↓
返回 AggregatedSearchResponse
```

### 适配器模式

所有适配器实现 `ISearchAdapter` 接口（`interfaces/search-adapter.interface.ts`）：

| 适配器 | 文件路径 | 数据源 |
|--------|---------|--------|
| `BaiduSearchAdapter` | `adapters/baidu-search.adapter.ts` | 百度 AI 搜索 |
| `WikipediaAdapter` | `adapters/wikipedia.adapter.ts` | 维基百科 |

接口方法：`search(query, limit)` + `isAvailable()`

### 缓存策略

- 缓存键格式：`search:{source}:{query}:{limit}`
- 统一 TTL：3600 秒（1 小时）
- Redis 未连接时静默降级，不影响搜索主流程
- 由 `SearchCacheService` 管理，支持 `get` / `set` / `delete` / `clearAll`

### 核心类型

| 类型 | 文件路径 | 说明 |
|------|---------|------|
| `SearchRequestDto` | `dto/search-request.dto.ts` | 搜索请求：query、sources?、limit?(1-50, 默认 10) |
| `SearchResultItem` | `dto/search-response.dto.ts` | 搜索结果项：title、snippet、url、source、metadata? |
| `AggregatedSearchResponse` | `dto/search-response.dto.ts` | 聚合响应：query、totalResults、sources(按数据源分组)、timestamp |
| `ISearchAdapter` | `interfaces/search-adapter.interface.ts` | 适配器接口：name、description、search()、isAvailable() |

## 模块协作

- **被 KnowledgeModule 调用**: `KnowledgeAnalysisService.performWebSearch()` 调用 `aggregateSearch()`，提取前 3 条知识点关键内容作为搜索词，失败不阻塞分析
- **导出**: `SearchAggregatorService`

## 注意事项

- **适配器注册**: 在 `SearchAggregatorService` 构造函数中硬编码注册，新增适配器需修改构造函数
- **环境变量**: Redis 配置（`REDIS_HOST`、`REDIS_PORT`、`REDIS_PASSWORD`）、百度搜索 API 配置（`BAIDU_SEARCH_API_KEY`）
- **容错设计**: `Promise.allSettled()` 确保单个数据源失败不影响其他数据源；Redis 未连接时静默降级
