## 1. 认证模块

### 1.1 用户注册

**接口**: `POST /auth/register`

**请求头**:
```
Content-Type: application/json
```

**请求体**:
```json
{
  "username": "zhangsan",
  "email": "zhangsan@example.com",
  "password": "SecurePassword123!"
}
```

**响应**: `201 Created`
```json
{
  "success": true,
  "message": "注册成功",
  "data": {
    "user": {
      "id": "uuid-string",
      "username": "zhangsan",
      "email": "zhangsan@example.com",
      "avatar_url": null,
      "preferences": {},
      "role": "user",
      "created_at": "2026-02-25T10:30:00Z"
    },
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expires_in": 900
  },
  "code": 201,
  "timestamp": "2026-02-25T10:30:00.000Z"
}
```

**错误响应**:
- `400 Bad Request`: 参数校验失败
- `409 Conflict`: 用户名或邮箱已被注册

### 2.5 触发知识点分析（SSE 流式响应）

**接口**: `POST /knowledge/analyze`

**请求头**:
```
Authorization: Bearer <access_token>
Content-Type: application/json
Accept: text/event-stream
```

**请求体**:
```json
{
  "date": "2026-02-25",
  "webSearchEnabled": false
}
```

**字段说明**:
- `date`: 分析的目标日期（可选，YYYY-MM-DD 格式，默认今天）
- `webSearchEnabled`: 是否启用联网搜索增强（可选，默认 false）

**响应**: `200 OK` (Server-Sent Events)

```
event: start
data: {"taskId":"task-uuid","model":"qwen-plus","startTime":"2026-02-25T10:30:00.000Z"}

event: chunk
data: {"content": "## 知识点分类\n\n### 前端开发"}

event: chunk
data: {"content": "\n- TypeScript 泛型约束..."}

event: done
data: {"tokenUsage":{"inputTokens":1500,"outputTokens":800,"totalTokens":2300,"model":"qwen-plus","totalCost":0.023},"processingTimeMs":3200}
```

**错误响应（前置校验）**:
```
{
  "success": false,
  "message": "2026-02-25 没有录入知识点，无法分析",
  "code": 400,
  "timestamp": "2026-02-25T10:30:00.000Z"
}
```

**SSE 运行时错误事件**:
```
event: error
data: {"message":"模型调用失败","code":"ANALYSIS_ERROR"}
```

**SSE 事件类型说明**:

| 事件 | 说明 |
|------|------|
| `start` | 分析开始，返回 taskId、model、startTime |
| `chunk` | AI 生成的内容片段（Markdown 格式） |
| `done` | 分析完成，返回 token 消耗和耗时 |
| `error` | 分析失败，返回错误信息 |

## 4. 通用规范

### 4.1 统一响应格式（ApiResponseDto）

**成功响应**:
```json
{
  "success": true,
  "message": "操作成功",
  "data": {},
  "code": 200,
  "timestamp": "2026-02-25T10:30:00.000Z"
}
```

**错误响应**:
```json
{
  "success": false,
  "message": "参数校验失败",
  "code": 400,
  "timestamp": "2026-02-25T10:30:00.000Z"
}
```

**字段说明**:
- `success`: 请求是否成功（boolean）
- `message`: 操作描述
- `data`: 响应数据（成功时存在）
- `code`: HTTP 状态码
- `timestamp`: 响应时间戳（ISO 8601）

---

### 4.2 认证方式

使用 **JWT Bearer Token** 认证：

```
Authorization: Bearer <access_token>
```

**Token 有效期**:
- access_token: 由 `JWT_EXPIRES_IN` 控制（默认 `15m`，即 900 秒）
- refresh_token: 由 `JWT_REFRESH_EXPIRES_IN` 控制（默认 `7d`）

**公开接口**（无需认证）:
- `POST /auth/register`
- `POST /auth/login`
- `POST /auth/refresh`

---

### 4.3 SSE 流式响应说明

分析接口使用 **Server-Sent Events (SSE)** 实现流式响应：

```javascript
// 前端使用示例（fetch + ReadableStream）
const response = await fetch('/api/knowledge/analyze', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${token}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ date: '2026-02-25', webSearchEnabled: false }),
});

const reader = response.body.getReader();
const decoder = new TextDecoder();

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  const text = decoder.decode(value);
  // 解析 SSE 事件
}
```
